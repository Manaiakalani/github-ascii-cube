# GitHub ASCII Cube

← Back to Cube GitHub Repo

About This Project

A faithful recreation of the 3D ASCII cube found in the footer of thegithubshop.com. The cube renders the GitHub Mona (Invertocat) logo as a texture on a rotating 3D box, then transforms the entire scene into ASCII art using a custom GLSL post-processing shader.

The original implementation was reverse-engineered from the GitHub Shop's production bundle and recreated as a standalone, zero-dependency HTML file (Three.js loaded via CDN).

Tech Stack

Three.js r170 WebGL 3D rendering engine
GLSL Shader Custom ASCII post-processing pass with sharpening & smoothstep
EffectComposer RenderPass → ShaderPass pipeline
Pointer Events API Unified mouse + touch drag handling

How It Works

Unlike typical ASCII art that maps characters to pixels on the CPU, this uses a GPU shader pipeline:

  • A BoxGeometry(50,50,50,32,32,32) is textured with the Mona image and rendered normally by Three.js
  • The rendered frame is passed to an EffectComposer post-processing pipeline
  • A custom fragment shader pixelizes the scene into a grid, computes greyscale intensity per cell, and looks up the corresponding ASCII character from a pre-rendered atlas texture
  • Characters ' ..<>#' form the brightness ramp (6 levels)
  • A Laplacian sharpening kernel + smoothstep crispens the final output

Performance

  • Zero garbage collection in animation loop — all Three.js objects pre-allocated
  • Device pixel ratio capped at 2× to prevent GPU overload on high-DPR screens
  • Debounced resize handler with proper texture disposal
  • Animation pauses automatically when tab is hidden
  • Responsive cell sizing: 4px → 5px → 6px → 9px across breakpoints
